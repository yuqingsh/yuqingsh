An intelligent point cloud processing software based on CloudCompare, supporting one-click classification of indoor and outdoor scanned point clouds. This project extends CloudCompare's functionality with AI-powered features for automated point cloud segmentation and analysis.

基于 CloudCompare 的点云智能处理软件，支持室内外扫描点云的一键分类。该项目通过 AI 驱动的功能扩展了 CloudCompare 的能力，实现自动化的点云分割与分析。
